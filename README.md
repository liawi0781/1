# 🚭 Трекер курения — Telegram-бот

Бот на русском языке, который помогает бросить курить.

## Возможности

- **🚬 Закурил** — отметка выкуренной сигареты (с кнопкой «Отменить»), счётчик за день и время, сколько продержался
- **💪 Хочу курить** — советы при тяге и отметка «Я удержался!»
- **📊 Статистика** — сегодня / вчера / среднее за неделю, на сколько % меньше куришь, текущая и лучшая серия без сигарет, сколько сигарет не выкурено и сколько денег сэкономлено
- **❤️ Здоровье** — этапы восстановления организма с прогресс-баром до следующего этапа
- **🎯 Лимит** — дневной лимит для постепенного снижения (0 — не курить совсем)
- **⚙️ Настройки** — изменить данные или сбросить всё

## Запуск

1. Создай бота у [@BotFather](https://t.me/BotFather) командой `/newbot` и скопируй токен.
2. Установи зависимости (нужен Python 3.10+):
   ```bash
   pip install -r requirements.txt
   ```
3. Запусти:
   ```bash
   BOT_TOKEN="123456:ABC..." python -m smoke_bot.bot
   ```
   На Windows (PowerShell):
   ```powershell
   $env:BOT_TOKEN="123456:ABC..."; python -m smoke_bot.bot
   ```

Необязательные переменные окружения:

| Переменная | По умолчанию | Описание |
|---|---|---|
| `DB_PATH` | `smoke_bot.sqlite3` | файл базы данных SQLite |
| `TZ_NAME` | `Europe/Moscow` | часовой пояс для подсчёта «сегодня» |

Данные хранятся в локальном файле SQLite. Бот должен работать постоянно, чтобы отвечать: на компьютере, на сервере или на хостинге.

# 🚭 Трекер курения — Telegram-бот

Бот на русском языке, который помогает бросить курить.

## Возможности

- **🚬 Закурил** — отметка одной штуки (с кнопкой «Отменить»), счётчик за день и время, сколько продержался
- **Отметки сообщением** — `+2` (сразу несколько), `14:30` (задним числом, если забыл), `+2 14:30`, или командой `/add 2 14:30`
- **💪 Хочу курить** — советы при тяге и отметка «Я удержался!»
- **📊 Статистика** — сегодня / вчера / среднее за неделю, на сколько % меньше куришь, текущая и лучшая серия без курения, сколько не выкурено и сколько денег сэкономлено
  - **📅 По дням** (`/days`) — график за 2 недели
  - **📝 История** (`/history`) — последние записи, ошибочные можно удалить
- **❤️ Здоровье** — этапы восстановления организма с прогресс-баром до следующего этапа
- **🎯 Лимит** — дневной лимит (0 — не курить совсем) с планом автоматического снижения: −1 каждый день, каждые 3 дня или каждую неделю
- **⚙️ Настройки** — каждый параметр меняется отдельно:
  - что куришь: сигареты, стики (IQOS, glo), сигариллы — бот говорит «3 стика», а не «3 сигареты»
  - сколько в день, цена пачки, штук в пачке
  - валюта: ₽, ₸, ₴, Br, $, € или своя
  - часовой пояс: кнопками или вручную (`UTC+5`, `Europe/Berlin`), «сегодня» считается по нему
  - сброс всех данных

База данных от прошлой версии обновляется автоматически при запуске, данные сохраняются.

## Запуск

1. Создай бота у [@BotFather](https://t.me/BotFather) командой `/newbot` и скопируй токен.
2. Установи зависимости (нужен Python 3.10+):
   ```bash
   pip install -r requirements.txt
   ```
3. Запусти:
   ```bash
   BOT_TOKEN="123456:ABC..." python -m smoke_bot.bot
   ```
   На Windows (PowerShell):
   ```powershell
   $env:BOT_TOKEN="123456:ABC..."; python -m smoke_bot.bot
   ```

Необязательные переменные окружения:

| Переменная | По умолчанию | Описание |
|---|---|---|
| `DB_PATH` | `smoke_bot.sqlite3` | файл базы данных SQLite |
| `TZ_NAME` | `Europe/Moscow` | часовой пояс по умолчанию (каждый может выбрать свой в настройках) |

Данные хранятся в локальном файле SQLite. Бот должен работать постоянно, чтобы отвечать: на компьютере, на сервере или на хостинге.
